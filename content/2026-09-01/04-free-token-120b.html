FREETOKEN / EDGE-NATIVE MoE SERVING

RTX 5090 + RAM으로 120B MoE를 실행할 수 있다

FreeToken은 모델 전체를 32GB VRAM에 올리는 대신 MoE expert pool을 host RAM에 둔다. GPU cache, PCIe fetch, CPU compute를 조합하는 방식이라 실행 가능 여부와 80GB GPU에 가까운 속도가 나오는지는 따로 봐야 한다.

gpt-oss-120b MXFP4 checkpoint의 크기다. 전체 116.83B 중 token당 약 5.13B가 활성화된다.

RTX 5090 32 GiB

전체 checkpoint를 VRAM에 상주시킬 수 없다. 일부 state와 자주 쓰는 expert만 GPU에 둬야 한다.

Published 5090 + 120B TPS 없음

FreeToken 논문에는 이 조합의 tok/s, TTFT, context benchmark가 없다.

01 / RUNTIME

GPU는 hot cache, RAM은 expert bank

MoE는 전체 parameter가 커도 token마다 일부 expert만 활성화된다. FreeToken은 매 step에 필요한 expert만 GPU로 가져오고, cache에 없으면 CPU에서 계산할 수도 있다.

02 / CAPACITY

RAM을 더하면 무엇이 해결되나

03 / VERDICT

가능한 조건과 아직 확인되지 않은 것

Dense 120B 모델을 뜻하는 이야기는 아니다. gpt-oss-120b처럼 token당 일부 expert만 쓰는 sparse MoE에 충분한 RAM과 지원 runtime을 붙였을 때만 RTX 5090 한 장으로 실행할 수 있다.

YES실행 경로는 있다

FreeToken 지원 목록에 gpt-oss-120b가 있으며 RTX 50 계열에서 MoE expert offload를 지원한다.

CONDITIONAL남는 RAM이 충분해야 한다

Checkpoint 외에도 OS, runtime, KV가 RAM을 쓴다. 96GB는 시작점으로 볼 수 있고 128GB면 여유가 더 생긴다.

NOT PROVEN속도는 공개 자료로 확인할 수 없다

FreeToken 논문에는 RTX 5090, RAM, gpt-oss-120b를 조합한 TPS나 TTFT 측정값이 없다.

!

구매하거나 배포하기 전에 직접 재야 한다. 정확한 checkpoint format과 남는 RAM부터 확인한다. PCIe generation과 lane 수, DRAM bandwidth, context와 KV 예산, 예상 concurrency도 고정한 뒤 ft bench bw와 실제 prompt set의 tok/s, TTFT, tail latency를 기록한다.
