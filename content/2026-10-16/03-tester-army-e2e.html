AGENTIC TESTING / WEB + MOBILE

에이전트가 실행하고, 검증된 동작을 반복한다

tester-army/e2e는 자연어로 화면 작업을 지시하는 agent step과 Playwright 방식의 locator assertion을 한 테스트에 결합한다. 검증을 통과한 agent 동작은 다음 실행에서 재생할 수 있어, 자연어 자동화와 결정적 확인을 함께 구성한다.

01 / TEST CONTRACT

자연어 동작과 정확한 검증을 한 테스트에 둔다

화면에서 여러 단계를 찾아가는 일은 에이전트에 맡기고, 중요한 결과는 역할·이름·상태를 기준으로 다시 확인한다.

agent.act()는 화면을 관찰하고 목표를 수행한다. 뒤따르는 locator assertion은 실제 제품 상태를 검사한다. 테스트에 에이전트 단계가 없으면 모델 설정 없이도 기존 E2E 검사만 실행할 수 있다.

02 / VERIFIED REPLAY

통과한 동작을 기록하고, 다음 실행에서 재생한다

캐시는 agent step의 실행을 덮어쓰지 않는다. 후속 확인이 성공한 동작만 다음 실행에 재사용하며, 화면이 달라지면 에이전트가 이어받는다.

≠

모델 비교 때는 캐시를 끈다. 캐시 키는 모델 이름 변경만으로 무효화되지 않는다. 같은 기록이 재생되면 새 모델이 화면을 조작하지 않으므로, 모델 간 동작을 비교할 때는 e2e run --no-cache를 사용한다.

03 / ENGINES

같은 테스트 API를 브라우저와 모바일에 연결한다

공통 test fixture와 검증 문법을 두고, 실행 대상에 맞는 engine package가 화면 관찰과 입력을 처리한다.

04 / HOW TO ADOPT

에이전트가 필요한 구간에만 모델을 둔다

자연어 동작은 적응성이 필요한 UI 흐름에 사용하고, 중요한 완료 조건은 안정된 selector로 고정한다.

01 / KEEP DETERMINISTIC

정확한 상태는 locator로 확인

결제 완료, 저장 표시, 계정 권한처럼 제품 요구사항으로 고정된 결과는 locator matcher로 확인한다. 이 단계는 모델 판단이 필요 없다.

EXPECT → UI STATE
02 / USE AGENT

찾아가기와 의미 기반 조작에 사용

레이아웃 변화가 있는 화면에서 목표를 수행하거나 여러 단계로 이어지는 조작을 자연어 agent step으로 표현한다.

GOAL → AGENT ACTIONS
03 / VERIFY REPLAY

기록은 통과한 흐름만 재사용

각 agent.act 뒤에 결과 검증을 둔다. 캐시 trace에서 재생, handoff, miss와 이유를 확인한다.

PASS → RECORD → REPLAY
MODEL모델 공급자

저장소는 사용자 구독, API key 또는 local model을 허용한다. 테스트에 agent step이 없으면 모델을 호출하지 않는다.

DATA텔레메트리

CLI 텔레메트리는 기본 활성화지만, 저장소 설명상 test 내용·앱 내용·credential을 보내지 않는다. 비활성화는 npx e2e telemetry disable로 설정한다.

VERSION버전 확인

2026-10-16 저장소 안내 기준으로 1.0 이전 개발 중이며 minor 버전 사이에도 API와 config가 바뀔 수 있다. 도입 시 버전을 고정하고 변경 로그를 확인한다.

!

이 페이지의 범위 replay cache는 반복 실행의 agent 동작 비용을 줄이는 메커니즘이다. 저장소 자료는 제품별 속도 향상이나 flaky test 감소율을 공통 조건으로 측정한 결과를 제시하지 않으므로, 실제 도입 효과는 우리 앱과 테스트 데이터로 따로 측정해야 한다.
